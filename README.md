# simple-quiz-bot-
A command-line quiz bot built with Python that gives the user 10 random questions in every quiz session.
It contains:
🎲 Random Questions — Selects 10 different questions randomly.
💬 Interactive Chat — Talks with the user through the terminal.
📝 Multiple Choice — A, B, C, or D answers.
✅ Instant Feedback — Tells you immediately if your answer is correct.
📊 Score System — Shows your score and percentage at the end.
🏆 Performance Messages — Gives different messages based on your score.
🔄 Replay Option — Start another quiz with a fresh set of questions.
🛡️ Input Validation — Prevents invalid answers such as X or numbers.
👤 Name Personalization — Greets the player by name.
🧩 Easy to Expand — You can easily add hundreds of new questions.
Tech used: Python, random, time, functions, lists/dictionaries, loops, conditionals, and input handling.
